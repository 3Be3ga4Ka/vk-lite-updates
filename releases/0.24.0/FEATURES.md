# VK Lite 0.24.0

## Что переработано отдельно от новых функций

Настройки приведены к общей системе шрифтов, цветов, отступов и сгруппированных строк. Вместо символов «✓/○» используются обычные переключатели: они меняются на месте, не пересоздавая экран. Основное окно навигации и окно настроек сохраняются при обычных переходах; содержимое меняется внутри. Изменение самой темы/масштаба может потребовать пересоздания Activity. Это не обещание сохранения всех экранов в памяти: Android по-прежнему может выгружать приложение.

Меню действий стало общей нижней панелью с реакциями, превью сообщения, четырьмя основными действиями, отдельными значками, раскрытием дополнительных действий, закрытием жестом по заголовку и адаптацией под ширину экрана. Есть управление откликом, превью и анимациями.

QMods больше не использует заявки GitHub. У значка есть локальный предпросмотр, цвет и настройки показа. Общий значок включает/удаляет сам пользователь в клиенте после явного согласия. Сервер проверяет владельца токена через users.get и не принимает произвольный заявленный ID. Это декоративный QMods-значок, не верификация личности VK. Изменения значков обновляют подписи, не пересоздавая весь экран.

Сервер **ещё не размещён на qmods.ru**. Его PHP-архив передаётся владельцу отдельно. Пока владелец его не установил, локальный показ работает, подключение общего значка показывает причину недоступности. Для чтения общих значков требуется согласие: серверу отправляются ID людей на экране, без имён, переписки и токена. Для подключения/удаления токен однократно передаётся на qmods.ru для проверки, без сохранения сервером. Старые неподтверждённые заявки не переносятся.

## 50 новых возможностей

### Настройки и профили

1. Поиск конкретной настройки по названию/описанию с переходом прямо к нужной строке, а не только фильтрация названий разделов.
2. Закрепление отдельных настроек в быстром доступе по удержанию строки.
3. Список только изменённых настроек, отличающихся от стандартных значений.
4. Сброс одной настройки из её контекстного меню.
5. Сброс параметров выбранного раздела, сохраняющий аккаунты и данные.
6. Сохранение текущего набора настроек как именованного профиля.
7. Предпросмотр изменений профиля перед применением.
8. Создание копии сохранённого профиля под новым именем.
9. Переименование профиля.
10. Удаление отдельного профиля.
11. Экспорт профиля/текущих настроек в JSON через системный выбор файла, без сессий и секретов.
12. Импорт JSON-профиля с ограничением размера, проверкой ключей, типов и допустимых значений до применения. Неизвестные параметры не импортируются.
13. Отмена последнего применения профиля с возвратом предыдущих настроек.
14. Готовый профиль экономии трафика: текстовая лента, Wi-Fi для скачивания, без автоматического перехода к следующему видео.
15. Профиль спокойной переписки: общие параметры без баннеров, повторных звуков, набора и автоматического прочтения. Индивидуальные исключения чатов сохраняются.
16. Профиль крупного интерфейса: крупнее текст, меньше анимаций, полные меню.

### Напоминания о сообщениях

17. Локальное напоминание о выбранном сообщении из его меню, с зашифрованным хранением текста.
18. Выбор произвольных даты и времени напоминания, помимо быстрых сроков.
19. Перенос напоминания на новый срок без создания копии.
20. Завершение напоминания и возвращение завершённого в активные.
21. Поиск по напоминаниям и фильтры активных, просроченных и завершённых.
22. Редактируемая заметка к напоминанию.
23. Передача напоминания в календарь телефона через системное подтверждение создания события.
24. Кнопки «Готово» и «Через 15 мин» непосредственно в уведомлении напоминания. Переход в исходное сообщение учитывает аккаунт.

### Сообщения и текст

25. Добавление/снятие отметки важного сообщения в VK с ожиданием подтверждения сервера.
26. Отдельный список важных сообщений, отмеченных этим клиентом в текущем чате, с запросом содержимого у VK и переходом к оригиналу. Последние до 100 отметок отображаются из локального индекса; сервер может ограничить доступ.
27. Удаление своего сообщения у всех участников по явному подтверждению. Пункт предлагается для недавних сообщений; окончательную доступность определяет VK.
28. Озвучивание текста сообщения системным движком Android с отдельной остановкой чтения. Для длинных сообщений действует лимит установленного TTS-движка.
29. Выбор скорости озвучивания сообщения.
30. Передача текста сообщения приложению перевода/обработки текста через системный ACTION_PROCESS_TEXT. Нужны Android 6+ и установленный обработчик; собственного сервиса перевода нет.
31. Поиск текста выбранного сообщения в браузере по явному действию пользователя.
32. Просмотр корректного JSON из сообщения с отступами; неподходящий текст не выдаётся за JSON.
33. Копирование отдельных блоков кода из сообщения с разметкой тройными обратными кавычками.
34. Выбор найденного в сообщении email и переход к созданию письма в почтовом приложении. Автоматической отправки нет.
35. Отправка картинки выбранного сообщения в другое приложение. Изображение ограничено по площади, чтобы не расходовать чрезмерно память старых телефонов.
36. Экспорт сообщения в самостоятельный HTML-файл с датой и счётчиком вложений, без встроенных токенов и исполняемой пользовательской разметки.
37. История изменений текста, которые клиент увидел в открытом чате. Хранение зашифровано; до 8 последних записей с текстом до 700 символов. Старые версии сообщений с сервера задним числом не восстанавливаются.
38. Статистика текста сообщения: символы, слова, строки и ориентировочное время чтения.

### Лента и загруженное медиа

39. Текстовая лента: вложения записей и репостов загружаются после нажатия, с сохранением обычного режима для других разделов.
40. Скрытие записей ленты с явной рекламной меткой VK. Это не обещание обнаружения всех видов рекламы.
41. Скрытие репостов в ленте без изменения подписок.
42. Настройка числа строк текста записи в ленте, включая показ всего текста.
43. Избранные скачанные файлы с отдельным фильтром библиотеки.
44. Алфавитная сортировка скачанных файлов.
45. Отдельный фильтр скачанных кружков.
46. Продолжение скачанного видео/ГС после закрытия проигрывателя или выгрузки процесса, отдельно от истории онлайн-видео.
47. Настройка скорости проигрывания скачанного медиа в автономном плеере.
48. Повтор скачанного медиа в автономном плеере.
49. Открытие скачанного файла в другом установленном проигрывателе с временным разрешением на чтение файла.
50. Остановка всей очереди скачивания медиа одной командой с сохранением частичных файлов для повторной попытки.

## Android 5 и ограничения

- Минимальная версия APK — Android 5.0/API 21. Для Android 5–5.1 добавлен отдельный вариант хранения AES-ключей с RSA-обёрткой AndroidKeyStore; существующие ключи и сессии на новых Android сохраняются.
- Добавлены совместимые системные службы и уведомления, календарные даты без java.time, обработчик прокрутки, чтение ориентации фото и другие замены отсутствующих API. На старых системах добавлен официальный ISRG Root X1 для HTTPS; проверка сертификатов и имени хоста остаётся включённой.
- Быстрый ответ из уведомления требует Android 7+, отдельные каналы/скрытие служебного канала и PiP — Android 8+. На Android 5–7 нельзя скрыть только уведомление фоновой службы через отдельный канал.
- Напоминания используют неточные системные сигналы: Android может задерживать доставку из-за сна и ограничений батареи. Нужны разрешённые уведомления; после перезапуска расписание восстанавливается системным получателем.
- Для входа нужен работоспособный системный WebView. Возможности старого WebView, кодеков и TLS на конкретной прошивке могут ограничить вход и медиа. Полное испытание на реальном Android 5 в этой сессии не выполнялось.
- Скачивание и расшифровка по-прежнему зависят от файлов и методов, которые выдаёт VK. Полная невидимость серверу не гарантируется.
- Выполнены компиляция, сборка и статическая проверка совместимости API. Отдельные тесты и эмулятор не запускались; проверка с реальным VK-аккаунтом и развёртывание PHP на qmods.ru не выполнялись.
- Исходники Android-приложения остаются закрытыми. Серверный архив содержит только запрошенные PHP-файлы и инструкцию для размещения владельцем сайта.
