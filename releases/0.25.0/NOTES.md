VK Lite 0.25.0 — оформление по присланным скриншотам VK

• В стиле VK — шесть значков снизу без подписей: главная, поиск, чаты, профиль, меню, уведомления. Панель переиспользуется между экранами; активный значок меняется на месте. Меню по удержанию открывает боковую навигацию.
• Шапки без дополнительного аватара слева, спокойная тёмная палитра, белые активные значки. Другие стили остаются отдельными вариантами.
• Чаты: крупнее аватары, однострочное превью по умолчанию, компактное время, нейтральные счётчики. Поиск и фильтры раскрываются кнопкой поиска; инструменты чатов доступны по нажатию заголовка. Настройки числа строк сохраняются.
• Меню: цветные плитки друзей, сообществ, музыки, видео, клипов, стикеров, закладок и настроек. Дополнительные разделы собраны в «Ещё». Стикеры из меню открывают каталог VK; отправка своих стикеров остаётся в чате.
• Лента: крупнее истории, скруглённые карточки на всю ширину и более спокойные кнопки под записями.
• Профиль пользователя: аватар и имя по центру, статус, кнопка публикации, отдельный блок друзей и переключатели музыки, фото, альбомов и видео. Музыка и фото загружаются в блоке профиля; ошибки допускают повтор без перезагрузки всей страницы.
• Уведомления: убраны повторяющийся заголовок и постоянная большая кнопка. Настройки, обновление и отметка просмотра доступны в шапке.

Для нового вида выберите Настройки → Оформление → Стиль интерфейса → VK. Светлая/тёмная тема и масштаб текста сохраняются. Поддержка Android 5/API 21 сохранена.

Это приближение к показанному интерфейсу, а не заявление о полном совпадении с официальным клиентом. Визуальная проверка на телефоне и проверка с реальным VK-аккаунтом не выполнялись. Возможности разделов по-прежнему зависят от ответов VK и прав сессии. Изменений в авторизации и сервере значков в этом выпуске нет. Исходники Android-приложения не публикуются.

Дополнение по новым пожеланиям:
• Настройки → Нижняя панель: 4–6 разделов из 13, перестановка, замена, удаление, подписи, восстановление набора VK. «Меню» сохраняется для доступа к настройкам. Настроенная панель доступна и в других вариантах оформления.
• Управление сообществами: отдельный раздел из настроек, «Ещё» и профиля сообщества. Список управляемых сообществ, уровень прав, основные сведения, статус и фото, настройки разделов/сообщений, фильтры комментариев, ссылки, участники, заявки, руководители и чёрный список. Для исключения/блокировки/отклонения заявки есть подтверждение; доступны причина и срок блокировки.
• Публикации от имени сообщества, отложенные и предложенные записи, действия с записями и удаление комментариев при наличии прав. Полномочия и аккаунт проверяются перед выполнением операции; успешность показывается только после подтверждения VK.
• Некоторые возможности официальной админ-панели (например, назначение руководителей, финансовые инструменты, бизнес-сервисы и аналитические кабинеты) в нативный экран не перенесены. Для них предусмотрен явно обозначенный переход в официальное веб-управление. Доступ через API зависит от роли и прав сессии; ошибки VK не маскируются под успех. Реальная работа на администраторском аккаунте в этой сессии не проверялась.
