VK Lite 0.25.1 — ответы сервера значков QMods

• Исправлена обработка HTML/предупреждений PHP вместо JSON: клиент показывает понятное сообщение, без технической ошибки JSONObject и без вывода содержимого серверного ответа.
• Добавлены сообщения для отсутствующего curl, прав папки _data, ошибки подключения хостинга к VK, ограничений частоты и неподтверждённой сессии.
• Ограничен размер ответа при подключении/отключении значка; схема, enabled, стиль и аккаунт проверяются до изменения локального состояния. Сообщение о подключении теперь обновляет статус экрана.
• Убрана устаревшая постоянная надпись о том, что сервер ещё не размещён.

Сервер qmods.ru работает на PHP 8.5.10. В версии сервера 2.1.0 curl_close() выводил предупреждение об устаревшем вызове перед JSON; это воспроизведено диагностическим запросом без действующего пользовательского токена. Для исправления на сайте замените только api/vklite/badges.php файлом из сервера 2.1.1. Папку _data/state.php не удаляйте.

Сервер 2.1.1 убирает curl_close(), отключает вывод диагностики в ответ и очищает собственный буфер перед JSON. Проверены PHP 8.5, POST-ответ без HTML, схема, защита файлов, конкурентные запросы, обработка повреждённой базы и лимит частоты. На qmods.ru правку загружает владелец; сервер агентом не обновлён. Действующий VK-токен в проверках не использовался.

Адрес API и schema=2 прежние. Исправление серверного файла работает и с APK 0.24/0.25. Для нового клиента сохранены Android 5/API 21, прежний пакет и подпись. APK собран; проверка с реальным VK-аккаунтом не выполнялась. Исходники Android-приложения не публикуются.
