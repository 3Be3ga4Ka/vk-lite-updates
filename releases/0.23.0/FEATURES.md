# VK Lite 0.23.0

50 новых возможностей; прежние настройки прочтения, набора, музыки, PiP и тем не выдаются за новые. Здесь перечислены дополнительные действия и расширения существующих возможностей.

## Быстрая приватность и настройки

1. Быстрая панель приватности по удержанию заголовка основного экрана; также доступна в центре настроек.
2. Временный общий приватный режим: 15 минут, час, 8 часов или до ручного отключения; окончание срока не меняет сохранённые настройки.
3. Нечиталка поверх исключений отдельных чатов: принудительно останавливает автоматические отметки прочтения.
4. Не-писалка поверх исключений чатов: останавливает отправку событий набора даже при разрешении в конкретной переписке.
5. Ограничение явного `account.setOnline` в общем API клиента; фоновая служба не может самостоятельно разрешить такой запрос.
6. Запрос согласия перед отправкой явного статуса онлайн. Разрешение действует только на один вызов; отказ и отсутствие ответа сохраняют запрет.
7. Ручная отправка `account.setOffline` с ожиданием ответа VK, без остановки работы клиента.
8. Отдельные принудительные режимы приватности и таймер для каждого сохранённого аккаунта.
9. Новый центр настроек с отдельными разделами: приватность, уведомления, видео/кружки, ГС, загрузки, QMods, оформление и аккаунты. Адаптивные карточки учитывают размер шрифта и системные отступы.
10. Поиск раздела настроек по названию и описанию; прежние настройки остаются в разделе «Дополнительные настройки».

## Загрузки и медиа без сети

11. Скачивание доступной прямой MP4-видеозаписи со страницы видео.
12. Скачивание клипа из меню «Поделиться клипом».
13. Скачивание кружка через его контекстное меню.
14. Скачивание MP3 голосового сообщения через меню дорожки.
15. Выбор качества скачивания среди прямых файлов, реально выданных VK.
16. Последовательная фоновая очередь медиа с прогрессом в уведомлении; библиотека отделена по аккаунтам.
17. Остановка текущего или ожидающего скачивания с сохранением уже полученной части файла.
18. Повторная попытка с докачкой через HTTP Range, если это поддерживает сервер; иначе скачивание начинается заново. Просроченную ссылку нужно получить новым скачиванием из исходного видео.
19. Библиотека скачанных видео, клипов, кружков и ГС с отдельным проигрывателем без сети.
20. Поиск по названию и фильтры библиотеки: видео, ГС, незавершённые и готовые.
21. Сортировка скачанного по занимаемому месту и отображение свободного пространства.
22. Локальное переименование скачанного файла.
23. Экспорт скачанного медиа в выбранную пользователем папку через системный диалог Android.
24. Отправка самого скачанного файла в другое приложение через «Поделиться».
25. Режим скачивания медиа только по Wi-Fi.
26. Настраиваемый лимит одного медиафайла: от 64 МБ до 4 ГБ, с проверкой свободного места.
27. Отдельная очистка остановленных и ошибочных загрузок, сохраняющая готовые файлы.

## Видеоплеер

28. Перемотка на ±10 секунд двойным нажатием у краёв видео; жест можно отключить.
29. Регулировка громкости вертикальным свайпом по правой половине видео.
30. Регулировка яркости окна свайпом по левой половине, без изменения системной яркости.
31. Блокировка касаний плеера с отдельной кнопкой разблокировки.
32. Повтор фрагмента A–B: установить начало и конец в текущих позициях либо отменить повтор.
33. Таймер остановки видео на 15, 30, 45, 60 или 90 минут.
34. Масштаб изображения: вписать, заполнить с обрезкой или растянуть.
35. Запоминание индивидуальной скорости для каждой видеозаписи, отдельно от общего значения.
36. Управление показом субтитров, когда текстовая дорожка присутствует в выданном VK потоке.

## Голосовые и кружки

37. Запрос расшифровки голосового на серверах VK через `messages.recogniseAudioMessage`, ожидание текста и отображение причины отказа или незавершённой обработки. Никакой отправки стороннему ASR-сервису.
38. Сохранение позиции голосового для продолжения позже; настройка отключается.
39. Пропуск тишины при воспроизведении ГС; музыка этим режимом не затрагивается.
40. Настройка начальной скорости новых голосовых: 0.75–2×, отдельно от музыки.
41. Выключаемая звуковая волна в дорожке ГС для более простого отображения.
42. Выбор скорости кружка в контекстном меню: 0.75–2×.
43. Переключение звука кружка и настройка запуска без звука.
44. Повтор кружков; отдельно от повторения обычных видео.
45. Выбор диаметра кружков 160–280 dp, ограниченного шириной экрана. В контекстном меню также есть открытие на весь экран и возврат в начало.

## Уведомления и QMods

46. Быстрый ответ из системного уведомления Android: текст отправляется по явному действию пользователя, с проверкой аккаунта и стабильным random_id для повторного действия.
47. Кнопка «Прочитано» в уведомлении. Это ручное действие, а не автоматическое прочтение нечиталкой.
48. Кнопка «На час тише» в уведомлении без отключения синхронизации.
49. Расширенные параметры карточек сообщений: звук, вибрация, баннер, значок на иконке, только личные чаты, история до шести сообщений и повторные звуковые сигналы. Системные настройки каналов Android имеют приоритет.
50. Добровольные декоративные QMods-значки из общего публичного реестра: подключение через заявку GitHub, отключение закрытием своей заявки, обновление реестра, обычное/компактное отображение и выключение значков. Значки отображаются рядом с именами в шапке чата, диалогах, профиле, авторах сообщений/постов, видео и поддерживаемых списках людей новых версий VK Lite.

## Практические ограничения

- Полная невидимость на сервере VK не гарантируется. Клиент блокирует свои явные запросы, автоматическое прочтение и набор; сервер может учитывать другие действия, веб-страницы и другие приложения. Ручное «Прочитано» выполняет прочтение по вашему нажатию.
- Для скачивания нужен прямой MP4/MP3, выданный VK. Защищённые потоки, только HLS/DASH и отсутствие прав доступа не обходятся. После выгрузки приложения остановленное скачивание нужно продолжить из библиотеки. Лимит APK не относится к сохранённым медиафайлам.
- Расшифровка зависит от доступности метода и самой записи на стороне VK. Текст может появиться позже; отказ VK не подменяется выдуманной расшифровкой.
- Значки не меняют имя VK. Для добровольного подключения нужен GitHub-аккаунт: в публичной заявке и реестре публикуются указанный VK ID и имя GitHub. Владение указанным VK ID не проверяется; значок декоративный и не означает верификацию личности. Реестр обновляется автоматически GitHub Actions; клиент кэширует его до 6 часов, доступно ручное обновление. Пользователи обычного VK и старых версий клиента эти значки не увидят.
- Старые версии без нового кода не получают перечисленные возможности до установки обновления.
- Выполнена необходимая компиляция и сборка APK. Отдельные тесты/эмулятор пропущены по прежней просьбе владельца. Проверки с реальным аккаунтом на телефоне в этой сессии не было; серверные операции и поведение Android требуют пользовательской проверки.
- APK подписан прежним ключом для установки поверх предыдущего VK Lite. Исходники Android-приложения не публикуются.
