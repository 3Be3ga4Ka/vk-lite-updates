# VK Lite 0.18.0 — 30 новых возможностей

1. **Открытие ссылок VK.** Поиск → Открыть ссылку VK. Поддержанные ссылки на запись, профиль, фото, видео, историю и чат открываются нативно; короткое имя страницы разрешается через VK.
2. **Поиск видео.** Раздел Поиск → Видео: обложки, заголовки и переход к воспроизведению.
3. **Поиск записей по VK.** Раздел Поиск → Записи: нативные карточки результатов newsfeed.search.
4. **История поисковых запросов.** До 10 недавних запросов, повтор запроса и очистка истории. Зашифрована и разделена по аккаунтам.
5. **Фильтры поиска людей.** Онлайн, пол и диапазон возраста. Сервер VK применяет фильтры к результатам.
6. **Продолжение поиска.** Постраничная загрузка людей, сообществ, записей и видео вместо ограничения первой страницей.
7. **Общие друзья.** Профиль другого пользователя → Подробнее → Общие друзья.
8. **Дни рождения друзей.** Друзья → Дни рождения. Выбор месяца; отображаются только открытые вашему аккаунту даты.
9. **Контакты сообществ.** Подробнее о сообществе → Контакты. Профили контактных лиц, опубликованные телефон и почта.
10. **Закладки страниц.** Раздел Закладки → Страницы: сохранённые пользователи и сообщества с пагинацией.
11. **Сохранение страниц.** Добавление пользователя/сообщества в закладки и удаление из них через Подробнее о профиле.
12. **Закладки видео.** Раздел Закладки → Видео: воспроизведение сохранённых видео и удаление из закладок.
13. **Отмена голоса в опросе.** Доступна, когда опрос не завершён и его автор разрешил отмену. Выполняется запрос VK, а не локальная подмена результата.
14. **Участники открытого опроса.** Выбор варианта ответа и список проголосовавших с пагинацией. Для анонимных опросов пункт скрыт.
15. **Создание опроса.** Редактор записи → Добавить опрос. Вопрос, 2–10 вариантов, анонимность и несколько ответов. Созданный опрос прикрепляется к записи и сохраняется в её черновике.
16. **Закрепление записи.** Закрепление и открепление на своей стене; на других стенах — только если VK явно разрешает действие.
17. **Удаление записи из закладок.** Меню сохранённой записи умеет удалять её из закладок; состояние подтверждается VK.
18. **Скрытие записи.** Меню записи → Скрыть на этом устройстве. Локально, отдельно для каждого аккаунта, до 200 записей.
19. **Возврат скрытых записей.** Настройки → Скрытые записи: просмотр и возврат отдельных записей. Настройка не меняет серверную ленту VK.
20. **Шаблоны быстрых ответов.** До 20 шаблонов по 500 символов: добавление, изменение, удаление и вставка в поле ввода. Зашифрованы, отдельно по аккаунтам.
21. **Упоминания участников.** В беседе → Скрепка → Упомянуть участника: выбор участника и вставка упоминания VK в текст перед отправкой.
22. **Отправка по Enter.** Настройки → Переписка. Enter отправляет сообщение; Shift+Enter сохраняет перенос строки. По умолчанию отключено.
23. **Счётчик длины сообщения.** Поле ввода ограничено 4096 символами; после 3500 отображается счётчик, на границе он выделяется цветом.
24. **Локальное название чата.** Удержание диалога → Настройки этого чата. Название меняется только на вашем устройстве; пустое поле возвращает имя VK.
25. **Цвет отдельной переписки.** Выбор цвета своих сообщений для конкретного чата независимо от общей темы. Цвет учитывает светлый/тёмный фон.
26. **Фильтр черновиков.** Вкладка Черновики в списке чатов: только загруженные диалоги с сохранённым текстом.
27. **Списки друзей VK.** Друзья → Списки друзей VK: выбор серверного списка и просмотр его участников с пагинацией.
28. **Сохранение фотографий.** Кнопка скачивания в галерее. Папку и имя выбирает системный проводник Android.
29. **Сохранение документов.** Меню документа → Сохранить файл. Прогресс, отмена, системный выбор места; без общего доступа к хранилищу. Файл сначала загружается во временный кэш, затем записывается в выбранное место; ограничение 128 МБ.
30. **Видео в отдельном окне.** Режим «Картинка в картинке» на поддерживаемых устройствах: кнопка В окно в плеере или уход на главный экран во время воспроизведения. Разрешение и доступность определяет Android.

Дополнительно: GitHub-канал установлен по умолчанию. Адреса qmods.ru и прежней неработающей ссылки GitHub Releases автоматически заменяются новым адресом; другие пользовательские HTTPS-каналы сохраняются.

Канал: https://raw.githubusercontent.com/3Be3ga4Ka/vk-lite-updates/main/stable.json

Компиляция и подпись выполнены. Отдельные тесты и эмулятор пропущены по просьбе пользователя; на реальном телефоне этот выпуск ещё не проверен. Возможности VK зависят от разрешений аккаунта и доступности API. Ошибки сервера не подменяются успешным результатом. Исходники не публикуются.
