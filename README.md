## Выпуск 0.20.0

Исправлены обрезанные подписи, адаптированы плитки и нижняя навигация, пересобран нижний блок меню без повторных пунктов. Работает во всех трёх стилях оформления.

Добавлен выбор видео из своей библиотеки прямо в чат и редактор записи. Управление видеоальбомами: добавление роликов, переименование, удаление альбома с сохранением видео, удаление ролика только из альбома. Сохранены видеотека, плеер, комментарии, история, загрузка видео и остальные возможности предыдущих выпусков.

## Обновления

В актуальном APK GitHub-канал встроен. Предыдущие стандартные адреса qmods.ru и GitHub Releases заменяются автоматически; другие пользовательские HTTPS-каналы сохраняются.

Для ручного переключения в 0.17.0: «Настройки → Обновления приложения → Канал обновлений»:

```text
https://raw.githubusercontent.com/3Be3ga4Ka/vk-lite-updates/main/stable.json
```

Клиент скачивает APK с прогрессом и отменой, сверяет файл и запускает системный установщик Android. Установку подтверждает пользователь. Android может откладывать фоновую проверку. В версиях 0.15 и старше механизма обновлений нет — первая установка выполняется вручную.

## Совместимость

Android 8.0 и новее, пакет `ru.vklite.nativeclient`. Доступность функций и приватного контента определяется разрешениями VK. Размер видео для загрузки — до 1 ГБ; обработку выполняет VK. Возобновления прерванной передачи по байтовому смещению нет.

APK собран и подписан тем же ключом. Отдельные тесты и эмулятор пропущены по просьбе владельца проекта; просмотр и загрузка с реальным аккаунтом на телефоне в этой сессии не проверялись.
