## Обновления

**В 0.18.0 GitHub-канал установлен по умолчанию.** Предыдущие стандартные адреса qmods.ru и GitHub Releases заменяются автоматически; другие пользовательские HTTPS-каналы сохраняются.

Для ручного переключения в 0.17.0 откройте «Настройки → Обновления приложения → Канал обновлений» и укажите:

```text
https://raw.githubusercontent.com/3Be3ga4Ka/vk-lite-updates/main/stable.json
```

Клиент скачивает APK с прогрессом и отменой, сверяет файл и открывает системный установщик Android. Установку подтверждает пользователь. Новые версии предлагаются при проверке канала; Android может откладывать фоновую задачу.

В версиях 0.15 и старше механизма обновлений нет — первая установка выполняется вручную.

## Совместимость

Android 8.0 и новее, пакет `ru.vklite.nativeclient`. Неофициальный клиент: доступность функций определяется правами аккаунта и ограничениями VK. Выпуск собран и подписан; отдельные тесты и эмулятор пропущены по просьбе владельца проекта, на реальном телефоне выпуск пока не проверен.
