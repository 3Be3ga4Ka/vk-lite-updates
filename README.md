## Выпуск 0.23.0

Новый центр настроек, быстрый приватный режим и 50 новых возможностей. Очередь скачивания видео, клипов, кружков и голосовых, библиотека без сети; жесты, A–B и таймер плеера; продолжение ГС и расшифровка VK; быстрые действия уведомлений и добровольные QMods-значки.

[Полный список 50 возможностей и ограничений](releases/0.23.0/FEATURES.md).

Для значка: «Настройки → Значки QMods → Подключить значок по желанию». Нужен GitHub-аккаунт; указанный VK ID и имя GitHub будут публичными. Закрытие своей заявки убирает добровольное подключение. Это декоративная отметка, без проверки владения VK ID и без статуса верификации VK. Клиент читает общий реестр; назначение обновляет GitHub Actions.

Приватность блокирует явный setOnline, автоматическое прочтение и набор этого клиента. Полная невидимость для сервера VK не гарантируется. Для скачивания нужен выданный VK прямой MP4/MP3; расшифровка зависит от VK. Установка и серверные операции с реальным аккаунтом на телефоне в этой сессии не проверялись.

## Обновления

В актуальном APK GitHub-канал встроен. Предыдущие стандартные адреса qmods.ru и GitHub Releases заменяются автоматически; другие пользовательские HTTPS-каналы сохраняются.

Для ручного переключения в 0.17.0: «Настройки → Обновления приложения → Канал обновлений»:

```text
https://raw.githubusercontent.com/3Be3ga4Ka/vk-lite-updates/main/stable.json
```

Клиент скачивает APK с прогрессом и отменой, сверяет файл и запускает системный установщик Android. Установку подтверждает пользователь. Android может откладывать фоновую проверку. В версиях 0.15 и старше механизма обновлений нет — первая установка выполняется вручную.

## Совместимость

Android 8.0 и новее, пакет `ru.vklite.nativeclient`. Доступность функций и приватного контента определяется разрешениями VK. Публикация видео на VK — до 1 ГБ; обработку выполняет VK. Исходящая передача не возобновляется по байтовому смещению. Входящее скачивание поддерживает докачку, если её допускает сервер.

APK собран и подписан тем же ключом. Отдельные тесты и эмулятор пропущены по просьбе владельца проекта; просмотр и загрузка с реальным аккаунтом на телефоне в этой сессии не проверялись.
