## Значки QMods

Заявки GitHub в новом клиенте не используются. Есть локальный предпросмотр и собственный API с проверкой владельца VK-токена. Общий значок не включается фиктивно, пока сервер не размещён.

- [Серверный архив для владельца qmods.ru](https://raw.githubusercontent.com/3Be3ga4Ka/vk-lite-updates/main/releases/0.24.0/QMods-Badges-Server-0.24.0.zip)
- [Инструкция по установке](releases/0.24.0/SERVER.md)

Архив — PHP 8.1+, curl и PDO SQLite. Владелец размещает badges.php по адресу /api/vklite/badges.php, конфигурирует хранилище вне public_html и HTTPS. Сервер агентом не развёрнут. Подключение общего значка требует явного согласия на передачу сессии qmods.ru для проверки. Сессия сервером не сохраняется. Чтение значков отдельно разрешается в настройках и передаёт только запрашиваемые ID, без переписки и имён. Значок декоративный, не верификация личности VK.

## Обновления

В актуальном APK GitHub-канал встроен. Предыдущие стандартные адреса qmods.ru и GitHub Releases заменяются автоматически; другие пользовательские HTTPS-каналы сохраняются.

Для ручного переключения в 0.17.0: «Настройки → Обновления приложения → Канал обновлений»:

```text
https://raw.githubusercontent.com/3Be3ga4Ka/vk-lite-updates/main/stable.json
```

Клиент скачивает APK с прогрессом и отменой, сверяет файл и запускает системный установщик Android. Установку подтверждает пользователь. Android может откладывать фоновую проверку. В версиях 0.15 и старше механизма обновлений нет — первая установка выполняется вручную.

## Совместимость

Android 5.0 и новее, пакет `ru.vklite.nativeclient`. Доступность функций и приватного контента определяется разрешениями VK. Публикация видео на VK — до 1 ГБ; обработку выполняет VK. Исходящая передача не возобновляется по байтовому смещению. Входящее скачивание поддерживает докачку, если её допускает сервер.

APK собран и подписан тем же ключом. Компиляция и статическая совместимость API проверены. Отдельные тесты и эмулятор пропущены по просьбе владельца проекта; просмотр и загрузка с реальным аккаунтом на телефоне в этой сессии не проверялись.

На Android 5 доступность входа зависит от системного WebView и прошивки; реального испытания на телефоне в этой сессии не было. PiP и каналы уведомлений требуют Android 8+, быстрый ответ из уведомления — Android 7+.
