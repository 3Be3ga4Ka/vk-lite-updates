# Обновления QVK

Канал QVK: `https://raw.githubusercontent.com/3Be3ga4Ka/vk-lite-updates/main/qvk/stable.json`.

Выпуски QVK используют теги `qvk-publicN`, а VK Lite продолжает использовать свой `stable.json` и теги `v…`.

После сборки и подписи `tools/publish_qvk.py APK --notes ОПИСАНИЕ.md --public N` автоматически создаёт черновик, загружает APK и `qvk-update.json`, затем публикует релиз. Workflow `qvk-release.yml` проверяет APK, SHA-256, подпись, пакет и versionCode и активирует `qvk/stable.json`. Это одновременно запускает распространение обновления: клиенты получают один и тот же опубликованный релиз, уведомление и окно. Повторный запуск workflow не создаёт новую рассылку для той же версии; публикация старой версии не откатывает канал.

В приложении проверка выполняется при открытии и раз в две минуты во время использования. «Пропустить» действует до следующего запуска/возврата приложения после пребывания в фоне. Системное уведомление отправляется один раз на версию; окно не зависит от разрешения Android на уведомления. Установка подтверждается системным установщиком после проверки файла.

Старые APK не могут получить новый код проверки без установки обновления. Для public26 и старее нужно установить первый выпуск с GitHub-каналом вручную либо доставить ссылку через прежнюю панель объявлений qmods.ru. Этот репозиторий не получает административные ключи qmods.ru или данные аккаунтов VK.
